# Calculator-flutter
 
📱 Flutter Calculator App

A simple and modern calculator app built with Flutter.
It supports basic arithmetic operations, percentage calculation, and toggling positive/negative numbers.

✨ Features

✅ Basic arithmetic operations (+, -, ×, ÷)
✅ Percentage (%) calculation
✅ Toggle sign (+/-)
✅ Clear (AC) and Delete (DEL) buttons
✅ Error handling for invalid expressions
✅ Responsive, modern UI with Flutter widgets

🚀 Getting Started
1. Clone the repo
git clone https://github.com/your-username/flutter_calculator.git
cd flutter_calculator

2. Install dependencies
flutter pub get

3. Run the app
flutter run
